# duanuoc2 (dừa nước bờ sông, vẽ lại 2026-11-16)
Vẽ lại bằng bộ vẽ kiểu hoa sen (src/caysen/duanuoc2.py, CO_RS=9 python3 duanuoc2.py one <0|1> DIR). 9 px/đơn vị game, PNG không nén mất.
2 dáng (Link: chỉ 2 dáng): 0 = bụi có buồng, 1 = bụi lá xanh không buồng. d = ngày, n = đêm. Không có bóng dưới gốc.
atlas.json: ox,oy = góc trên trái so với neo (gốc bụi, đơn vị game), gw,gh = cỡ vẽ (đơn vị game). Godot: offset=(ox,oy), scale=1/9.
Chưa gắn vô game (game vẫn dùng caylang/duanuoc 4 dáng cũ).
