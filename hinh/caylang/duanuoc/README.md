# duanuoc
Xuất LẠI từ code gốc src/duanuoc/ ở 9 px/đơn vị game (bản web img/duanuoc.webp chỉ 5 px). Cùng mô hình, cùng khung, cùng tên khung với bản game; không vẽ lại.
Màu: chỉnh "sâu lá" (src/nen/sau_la.py) k=0 cho khớp bản game.
d = ngày, n = đêm. Cây trái: d<dáng><chín>; chuối dw* = chuối rừng.
atlas.json: ox,oy = góc trên trái so với neo (tâm ô, đơn vị game), gw,gh = cỡ vẽ (đơn vị game). Godot: offset=(ox,oy), scale=1/9.
