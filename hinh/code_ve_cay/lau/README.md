# Cỏ lau (reeds), v638

Kit: `lau.py`, class `Lau` (blades and helpers from `../co`). Draw it with `python3 lau.py 0,1,2,3 [n] tag` or
`python3 lau.py atlas OUTDIR OUTDIR/lau.json`; it goes into the game with `../co/patch_wild.py`.

A clump of the tall wild cane grass of the delta's banks, in flower:
- a fountain of 34-42 long narrow arching leaves at the foot (3 dry ones);
- 8-11 tall slim canes (2.0-2.5 m), all leaning a little the same way (the wind), green low down turning straw
  toward the top, a node or two with a long leaf peeling off;
- on each cane a long silky plume streaming downwind, built of long slim strands of silk like the barbs of a
  feather (shaded strands, body, then sunny strands over them), white on the sunny side, beige-grey on the other.
Earlier tries that were dropped: a smooth feather outline (read as a white leaf), short bristle teeth (read as
crescents), short cross wisps (read as bandages).

About the old reed's size (±40 game units wide, ~80 tall). Frames d0-d3 (plants.reed, seed & 3), n0-n3 at night;
sheet `img/lau.webp`, table `atlas.json`.
