# Trang trí / đồ vật cho Godot (xuất 11-13)
9 px/đơn vị game, mỗi khung 1 PNG, không nén mất, không thu nhỏ. Neo = tâm ô (giống CONGTRINH). Godot: offset=(ox,oy), scale=1/9.
Khung: d<biến thể 0-2> = ngày, n<0-2> = đêm. Biến thể = web (t%3). MỖI LOẠI 1 THƯ MỤC, code đặt bao nhiêu cái cũng dùng chung file.
