# dao (cây đào)
Xuất từ code vẽ gốc của game web (at.plants.dao.draw) ở 9 px/đơn vị, PNG không mất nét. Khung d<seed + 4*mùa>: mùa 0 xuân (hoa hồng), 1 hạ, 2 thu, 3 mùa khô. Chỉ ngày.
atlas.json: ox,oy = góc trên trái so với neo (tâm ô, đơn vị game), gw,gh = cỡ vẽ (đơn vị game). Godot: offset=(ox,oy), scale=1/9.
