# xoai2
Cây xoài vẽ mới 2026-11-26 theo dáng xoài thật: thân cong, gốc loe đứng phẳng trên đất, chạc 3 nhánh, tán vòm rộng
lồi lõm gồm các túm lá rủ ở đầu cành, mỗi chùm sáng phía nắng và tối ở bụng; trái thòng thành chùm 2-4 trái ở mép tán.
Kiểu tô dừa nước (bộ vẽ caysen, sáng tối từng điểm ảnh, không bóng, viền mỏng cùng màu lá). Màu lấy từ xoài cũ. Cỡ bằng xoài cũ.
Code: code_ve_cay/xoai2/xoai2.py (cần caysen, thuysinh, hoaco, co).
Khung: d = ngày, n = đêm; d<dáng><chín>: dáng 0 / 1; chín 0 = xanh, 1 = chín. 8 ảnh: d00 d01 d10 d11 n00 n01 n10 n11.
9 px/đơn vị game. atlas.json: ox,oy = góc trên trái so với neo (gốc cây, đơn vị game), gw,gh = cỡ vẽ. Godot: offset=(ox,oy), scale=1/9.
Chưa gắn vào game (game vẫn dùng caytrai/xoai).
