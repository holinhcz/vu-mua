# dudu2 (cây đu đủ, vẽ lại 2026-11-16)
Vẽ lại bằng bộ vẽ kiểu hoa sen (src/caysen/dudu2.py, CO_RS=9 python3 dudu2.py one <dáng><chín> DIR). 9 px/đơn vị game, PNG không nén mất.
Khung d<dáng><chín>: dáng 0 / 1 (dáng 1 thấp, tán dù); chín 0 = trái xanh, 1 = trái chín. d = ngày, n = đêm. 8 ảnh. Không bóng dưới gốc.
atlas.json: ox,oy = góc trên trái so với neo (gốc cây, đơn vị game), gw,gh = cỡ vẽ. Godot: offset=(ox,oy), scale=1/9.
Chưa gắn vô game.
