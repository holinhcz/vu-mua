# lantern (đèn lồng đỏ trên trụ gỗ)
Xuất từ code vẽ gốc của game web (at.builds.lantern.draw) ở 9 px/đơn vị, PNG không mất nét. d0 (code vẽ không đổi theo seed). Chỉ ngày; đêm dùng night_mat + quầng sáng của Godot.
atlas.json: ox,oy = góc trên trái so với neo (tâm ô, đơn vị game), gw,gh = cỡ vẽ (đơn vị game). Godot: offset=(ox,oy), scale=1/9.
